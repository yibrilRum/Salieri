🧱 Core Functionalities Implemented
1. save_project(score)

Interactively asks the user for a filename.

Supports .xml (MusicXML export) and .m21data (binary pickle).

Writes directly to the project directory via project_paths.project_path().

Catches and reports all exceptions cleanly.

2. load_project(filename)

Attempts to load a user-specified project.

Supports both .xml (via music21.converter.parse) and .m21data (via pickle).

Returns a new blank stream.Score() if the load fails (never crashes).

Logs all load actions.

3. save_user_input(user_input)

Appends any string (usually menu choices or filenames) to a persistent session log.

Includes precise timestamps.

Protects against I/O errors with a fallback message.

4. start_new_session_log()

Marks the start of each interactive session in the log file.

Useful for debugging or reviewing user actions later.

5. list_saved_projects()

Dynamically scans the projects/ directory for valid save files.

Returns them as a sorted list for menus to display.

📘 Step 3 — project_paths.py Implementation & Integration

🧭 Step Context

This step follows the successful rebuild of the I/O layer (io_manager.py), which now handles all project saving, loading, and logging operations.
For these I/O operations to function reliably, Salieri needs a centralized, safe directory structure — one that prevents hard-coded paths and ensures all data (projects and logs) are properly organized.

Thus, this step introduces the project_paths.py module:
a small but essential subsystem responsible for defining and maintaining the filesystem structure.

🎯 Step Goal

Objective:
Implement a lightweight path manager that:

Defines the root, project, and log directories.

Automatically creates missing directories.

Returns full, safe, cross-platform file paths.

Keeps all path logic in one place (to avoid repetition and confusion across modules).

🧱 Key Responsibilities
Function	Description
get_base_dir()	Returns the absolute root of the Salieri project.
get_project_dir()	Returns path to /projects directory.
get_log_dir()	Returns path to /projects/logs subdirectory.
ensure_project_dir()	Ensures both directories exist before any I/O operation.
project_path(filename)	Builds a full path for a given project filename.
log_path()	Returns path to the active session log file (auto-dated).
🏗️ Implementation Summary

Filename:
scorecreator/project_paths.py

Core Code Excerpt:

def project_path(filename: str) -> str:
    ensure_project_dir()
    return os.path.join(get_project_dir(), filename)

def log_path() -> str:
    ensure_project_dir()
    today = datetime.now().strftime("%Y-%m-%d")
    return os.path.join(get_log_dir(), f"session_log_{today}.txt")

🧠 Design Principles
Principle	Explanation
Single Source of Truth	No other file defines or manipulates directory paths. All references go through project_paths.
Fail-Safe Design	Any save/load operation automatically triggers ensure_project_dir().
Cross-Platform Compatibility	Built with os.path for universal compatibility (macOS, Linux, Windows).
Non-invasive	Returns file paths only — never writes or modifies files directly.
Time-Aware Logging	Daily session log filenames prevent overwriting and make chronological debugging easy.
